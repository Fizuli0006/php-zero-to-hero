# Introduction to PHP

What is PHP? How does PHP run on a server and in the CLI? Create your first PHP script.

## Key concepts

PHP is a server-side scripting language commonly used to build dynamic web applications. A PHP file is interpreted by the PHP runtime. The browser receives the output, not the PHP source code.

## Example

Run the example from the repository root:

```bash
php lessons/01-introduction/examples/example.php
```
