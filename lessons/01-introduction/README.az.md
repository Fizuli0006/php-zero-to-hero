# Introduction to PHP

PHP nədir? PHP serverdə və CLI-da necə işləyir? İlk PHP skriptimizi yaradırıq.

## Əsas anlayışlar

PHP server tərəfli skript dilidir və dinamik veb tətbiqlərin hazırlanmasında istifadə olunur. PHP faylı PHP işləmə mühiti tərəfindən icra edilir. Brauzer PHP mənbə kodunu deyil, onun nəticəsini alır.

## Nümunə

Repository-nin əsas qovluğundan başladın:

```bash
php lessons/01-introduction/examples/example.php
```

## Praktika

Tapşırıqlar üçün [`../../exercises/README.md`](../../exercises/README.md) faylına baxın. Nümunə həllərə baxmazdan əvvəl öz həllinizi yazın.

## Əlavə çalışma

- İstifadə olunan funksiya və dil imkanlarını PHP rəsmi sənədlərində oxuyun.
- Nümunəni dəyişdirin və başlamazdan əvvəl nəticəni təxmin edin.
- Kodu öz sözlərinizlə izah edin.
