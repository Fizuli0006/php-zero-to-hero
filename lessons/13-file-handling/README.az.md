# File Handling

Faylları oxumaq/yazmaq, qovluqlar və yüklənən faylların yoxlanması.

## Əsas anlayışlar

Açıq fayl yollarından istifadə edin və xətaları idarə edin. Upload zamanı xəta kodunu, ölçünü, MIME tipini və yaradılmış fayl adını yoxlayın. Orijinal ada etibar etməyin.

## Nümunə

Repository-nin əsas qovluğundan başladın:

```bash
php lessons/13-file-handling/examples/example.php
```

## Praktika

Tapşırıqlar üçün [`../../exercises/README.md`](../../exercises/README.md) faylına baxın. Nümunə həllərə baxmazdan əvvəl öz həllinizi yazın.

## Əlavə çalışma

- İstifadə olunan funksiya və dil imkanlarını PHP rəsmi sənədlərində oxuyun.
- Nümunəni dəyişdirin və başlamazdan əvvəl nəticəni təxmin edin.
- Kodu öz sözlərinizlə izah edin.
