# File Handling

Read and write files, work with directories, and validate uploads.

## Key concepts

Use explicit paths and handle failures. For uploads, check upload errors, size, MIME type, and generated destination names. Never trust the original filename.

## Example

Run the example from the repository root:

```bash
php lessons/13-file-handling/examples/example.php
```
