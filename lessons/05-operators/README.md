# Operators

Arithmetic, comparison, logical, concatenation, and null-coalescing operators.

## Key concepts

Use === for strict comparison when type matters. The null-coalescing operator ?? provides a fallback when a value is null or missing.

## Example

Run the example from the repository root:

```bash
php lessons/05-operators/examples/example.php
```
