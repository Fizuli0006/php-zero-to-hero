# Operators

Riyazi, müqayisə, məntiqi, birləşdirmə və null coalescing operatorları.

## Əsas anlayışlar

Tip də vacibdirsə, sərt müqayisə üçün === istifadə edin. ?? operatoru dəyər null və ya mövcud olmadıqda alternativ dəyər verir.

## Nümunə

Repository-nin əsas qovluğundan başladın:

```bash
php lessons/05-operators/examples/example.php
```

## Praktika

Tapşırıqlar üçün [`../../exercises/README.md`](../../exercises/README.md) faylına baxın. Nümunə həllərə baxmazdan əvvəl öz həllinizi yazın.
