# PHP Web Security

XSS, CSRF, SQL injection, session security, secrets, and production configuration.

## Key concepts

Security is a set of habits: validate input, escape output, parameterize SQL, protect state-changing requests with CSRF tokens, store secrets outside source control, and disable detailed errors in production.

## Example

Run the example from the repository root:

```bash
php lessons/20-security/examples/example.php
```
