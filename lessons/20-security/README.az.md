# PHP Web Security

XSS, CSRF, SQL injection, session security, secrets və production konfiqurasiyası.

## Əsas anlayışlar

Təhlükəsizlik bir neçə vərdişdən ibarətdir: girişi yoxlayın, çıxışı escape edin, SQL parametrindən istifadə edin, məlumat dəyişən sorğuları CSRF token ilə qoruyun, məxfi dəyərləri koddan kənarda saxlayın və production-da detallı xətaları söndürün.

## Nümunə

Repository-nin əsas qovluğundan başladın:

```bash
php lessons/20-security/examples/example.php
```

## Praktika

Tapşırıqlar üçün [`../../exercises/README.md`](../../exercises/README.md) faylına baxın. Nümunə həllərə baxmazdan əvvəl öz həllinizi yazın.

## Əlavə çalışma

- İstifadə olunan funksiya və dil imkanlarını PHP rəsmi sənədlərində oxuyun.
- Nümunəni dəyişdirin və başlamazdan əvvəl nəticəni təxmin edin.
- Kodu öz sözlərinizlə izah edin.
