# Loops

for, while, do-while, and foreach loops.

## Key concepts

Use foreach to iterate over arrays. Make sure while-loop conditions can eventually become false to avoid accidental infinite loops.

## Example

Run the example from the repository root:

```bash
php lessons/07-loops/examples/example.php
```
