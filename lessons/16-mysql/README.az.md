# MySQL Fundamentals

Relational database, cədvəl, sütun, primary key, foreign key və əlaqələr.

## Əsas anlayışlar

Cədvəlləri obyektlərə uyğun layihələndirin. Düzgün data type seçin, primary key təyin edin və əlaqələri qorumaq üçün foreign key istifadə edin.

## Nümunə

Repository-nin əsas qovluğundan başladın:

```bash
php lessons/16-mysql/examples/example.php
```
