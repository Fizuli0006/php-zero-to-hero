# CRUD Application

Məlumat əlavə etmək, oxumaq, yeniləmək və silmək.

## Əsas anlayışlar

CRUD bir çox verilənlər bazalı tətbiqin əsasını təşkil edir. Girişi yoxlayın, prepared statement istifadə edin və update/delete əməliyyatlarının gözlənilən sətri dəyişdirdiyini yoxlayın.

## Nümunə

Repository-nin əsas qovluğundan başladın:

```bash
php lessons/18-crud/examples/example.php
```

## Praktika

Tapşırıqlar üçün [`../../exercises/README.md`](../../exercises/README.md) faylına baxın. Nümunə həllərə baxmazdan əvvəl öz həllinizi yazın.

## Əlavə çalışma

- İstifadə olunan funksiya və dil imkanlarını PHP rəsmi sənədlərində oxuyun.
- Nümunəni dəyişdirin və başlamazdan əvvəl nəticəni təxmin edin.
- Kodu öz sözlərinizlə izah edin.
