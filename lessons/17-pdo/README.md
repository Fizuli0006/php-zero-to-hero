# PDO and Prepared Statements

PDO connections, prepared statements, parameter binding, and transactions.

## Key concepts

Use PDO exceptions and prepared statements. Never concatenate untrusted input into SQL. Keep credentials outside version control.

## Example

Run the example from the repository root:

```bash
php lessons/17-pdo/examples/example.php
```
