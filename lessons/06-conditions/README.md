# Conditions

if, elseif, else, match, and conditional expressions.

## Key concepts

Use if/elseif for branching and match when comparing one expression against several exact alternatives. match uses strict comparison.

## Example

Run the example from the repository root:

```bash
php lessons/06-conditions/examples/example.php
```
