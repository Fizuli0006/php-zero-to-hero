# Exercises / Tapşırıqlar

Complete these exercises after reading the related module. Start with your own solution; sample solutions are in `solutions/`.

| ID | Module | Exercise |
|---|---|---|
| EX-01 | 01–02 | Print your name and a short introduction. |
| EX-02 | 03–05 | Store product name, price, and quantity; calculate the total. |
| EX-03 | 06 | Convert a numeric score into a grade using `match`. |
| EX-04 | 07–08 | Calculate the average of a list of student scores. |
| EX-05 | 09 | Write a typed function that calculates a discounted price. |
| EX-06 | 10 | Create a form that validates a name and email on the server. Escape output. |
| EX-07 | 12 | Count page visits with a session. |
| EX-08 | 13 | Write text to a file and read it back, handling failures. |
| EX-09 | 14–15 | Create a `Student` class and validate its score. |
| EX-10 | 16–18 | Create a students table and implement PDO-based CRUD. |
| EX-11 | 19 | Implement password hashing and verification. |
| EX-12 | 20 | Add output escaping and CSRF protection to a state-changing form. |

## Azerbaijani

Hər tapşırığı aid olduğu moduldan sonra edin. Əvvəl öz həllinizi yazın; nümunə həllər `solutions/` qovluğundadır.

- EX-01: Adınızı və qısa təqdimatınızı ekrana çıxarın.
- EX-02: Məhsulun adını, qiymətini və sayını saxlayıb yekun qiyməti hesablayın.
- EX-03: `match` ilə balı qiymətə çevirin.
- EX-04: Tələbə balları massivinin ortalamasını hesablayın.
- EX-05: Endirimli qiyməti hesablayan tipli funksiya yazın.
- EX-06: Ad və email-i serverdə yoxlayan forma yaradın, çıxışı escape edin.
- EX-07: Sessiya ilə səhifə ziyarətlərini sayın.
- EX-08: Fayla mətn yazın və oxuyun, xətaları idarə edin.
- EX-09: `Student` sinfi yaradın və balı yoxlayın.
- EX-10: students cədvəli yaradın və PDO CRUD hazırlayın.
- EX-11: Şifrə hash-i yaradın və yoxlayın.
- EX-12: Məlumat dəyişən formaya output escaping və CSRF qoruması əlavə edin.
