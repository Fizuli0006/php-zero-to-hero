# Functions

Funksiyalar, parametr, default dəyər, return type, variadic və closure.

## Əsas anlayışlar

Funksiyalar təkrar istifadə olunan davranışı bir yerə toplayır. Hər funksiyanın aydın bir məsuliyyəti olsun və mümkün olduqda parametr/qaytarma tiplərini göstərin.

## Nümunə

Repository-nin əsas qovluğundan başladın:

```bash
php lessons/09-functions/examples/example.php
```

## Praktika

Tapşırıqlar üçün [`../../exercises/README.md`](../../exercises/README.md) faylına baxın. Nümunə həllərə baxmazdan əvvəl öz həllinizi yazın.

## Əlavə çalışma

- İstifadə olunan funksiya və dil imkanlarını PHP rəsmi sənədlərində oxuyun.
- Nümunəni dəyişdirin və başlamazdan əvvəl nəticəni təxmin edin.
- Kodu öz sözlərinizlə izah edin.
