# PHP Syntax

Learn PHP tags, statements, semicolons, and comments.

## Key concepts

PHP code is commonly placed inside <?php ... ?>. A statement usually ends with a semicolon. Use // or /* ... */ for comments.

## Example

Run the example from the repository root:

```bash
php lessons/02-syntax/examples/example.php
```
