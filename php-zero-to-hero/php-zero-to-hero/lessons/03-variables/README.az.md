# Variables and Constants

Dəyişənlər, adlandırma qaydaları, scope və sabitlər.

## Əsas anlayışlar

Dəyişənlər $ işarəsi ilə başlayır. Adlar böyük-kiçik hərfə həssasdır. Aydın adlardan istifadə edin. Sabitlər const və ya define() ilə elan edilə bilər.

## Nümunə

Repository-nin əsas qovluğundan başladın:

```bash
php lessons/03-variables/examples/example.php
```

## Praktika

Tapşırıqlar üçün [`../../exercises/README.md`](../../exercises/README.md) faylına baxın. Nümunə həllərə baxmazdan əvvəl öz həllinizi yazın.
