# Variables and Constants

Variables, naming rules, scope, and constants.

## Key concepts

Variables start with $. Names are case-sensitive. Prefer descriptive names. Constants can be declared with const or define().

## Example

Run the example from the repository root:

```bash
php lessons/03-variables/examples/example.php
```
