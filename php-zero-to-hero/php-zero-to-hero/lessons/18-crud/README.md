# CRUD Application

Create, read, update, and delete database records.

## Key concepts

CRUD is the foundation of many data-driven applications. Validate inputs, use prepared statements, and check whether updates or deletes affected the expected row.

## Example

Run the example from the repository root:

```bash

```
