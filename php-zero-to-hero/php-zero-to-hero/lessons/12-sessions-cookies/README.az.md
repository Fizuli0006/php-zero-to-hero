# Sessions and Cookies

Sessiyanın başladılması, məlumat saxlanması, cookie parametrləri və təhlükəsizlik.

## Əsas anlayışlar

Çıxış göndərilməzdən əvvəl sessiyanı başladın. HTTPS mühitində təhlükəsiz cookie parametrləri seçin və autentifikasiyadan sonra session ID-ni yeniləyin.

## Nümunə

Repository-nin əsas qovluğundan başladın:

```bash
php lessons/12-sessions-cookies/examples/example.php
```

## Praktika

Tapşırıqlar üçün [`../../exercises/README.md`](../../exercises/README.md) faylına baxın. Nümunə həllərə baxmazdan əvvəl öz həllinizi yazın.

## Əlavə çalışma

- İstifadə olunan funksiya və dil imkanlarını PHP rəsmi sənədlərində oxuyun.
- Nümunəni dəyişdirin və başlamazdan əvvəl nəticəni təxmin edin.
- Kodu öz sözlərinizlə izah edin.
