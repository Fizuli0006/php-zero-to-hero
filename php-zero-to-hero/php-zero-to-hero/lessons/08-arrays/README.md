# Arrays

Indexed, associative, and multidimensional arrays; common array functions.

## Key concepts

Arrays store multiple values. Associative arrays use named keys. Use array_map, array_filter, and array_reduce when they make transformations clearer.

## Example

Run the example from the repository root:

```bash
php lessons/08-arrays/examples/example.php
```
