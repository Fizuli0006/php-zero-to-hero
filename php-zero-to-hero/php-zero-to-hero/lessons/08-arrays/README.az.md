# Arrays

İndeksli, assosiativ və çoxölçülü massivlər; əsas array funksiyaları.

## Əsas anlayışlar

Massivlər bir neçə dəyəri saxlayır. Assosiativ massivlər adlandırılmış açarlardan istifadə edir. Dəyərləri çevirmək üçün uyğun olduqda array_map, array_filter və array_reduce istifadə edin.

## Nümunə

Repository-nin əsas qovluğundan başladın:

```bash
php lessons/08-arrays/examples/example.php
```

## Praktika

Tapşırıqlar üçün [`../../exercises/README.md`](../../exercises/README.md) faylına baxın. Nümunə həllərə baxmazdan əvvəl öz həllinizi yazın.

## Əlavə çalışma

- İstifadə olunan funksiya və dil imkanlarını PHP rəsmi sənədlərində oxuyun.
- Nümunəni dəyişdirin və başlamazdan əvvəl nəticəni təxmin edin.
- Kodu öz sözlərinizlə izah edin.
