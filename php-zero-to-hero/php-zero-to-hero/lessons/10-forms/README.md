# HTML Forms and Validation

GET and POST forms, server-side validation, and HTML escaping.

## Key concepts

Never trust browser input. Validate data on the server and escape untrusted text before inserting it into HTML. htmlspecialchars() is a basic output-escaping tool.

## Example

Run the example from the repository root:

```bash
php lessons/10-forms/examples/example.php
```
