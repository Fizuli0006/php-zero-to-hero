# Object-Oriented PHP

Classes, objects, constructors, visibility, inheritance, interfaces, traits, and enums.

## Key concepts

Encapsulation keeps data and behavior together. Prefer composition when it makes relationships simpler. Use interfaces to define contracts.

## Example

Run the example from the repository root:

```bash
php lessons/14-oop/examples/example.php
```
