# Contributing

Thank you for helping improve PHP Zero to Hero!

## Ways to contribute

- Fix a typo or improve an explanation.
- Add a beginner-friendly example.
- Add an exercise with a clear expected result.
- Improve Azerbaijani or English translations.
- Report an incorrect or outdated PHP practice.

## Guidelines

1. Keep examples compatible with PHP 8.4+.
2. Prefer readable code over clever code.
3. Use strict types in examples where it helps explain type safety.
4. Never include real passwords, API keys, or personal data.
5. Explain security implications when handling user input, files, or database queries.
6. Keep English and Azerbaijani lesson content aligned.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] Code examples run without syntax errors.
- [ ] Both language versions are updated when relevant.
- [ ] No secrets or private data are included.
- [ ] Documentation links work.
