# PHP Öyrənmə Yol Xəritəsi

1. **Dil əsasları:** sintaksis, dəyişənlər, tiplər, operatorlar, şərtlər, dövrlər.
2. **Təkrar istifadə olunan kod:** massivlər, funksiyalar, namespace və Composer.
3. **Veb əsasları:** HTTP, sorğu metodları, formalar, validasiya, escaping.
4. **Vəziyyət və fayllar:** sessiyalar, cookie-lər, fayl sistemi, upload.
5. **Obyekt-yönümlü PHP:** siniflər, interfeyslər, trait-lər, exception.
6. **Verilənlər bazası:** əlaqəli model, MySQL, PDO, transaction, CRUD.
7. **Tətbiq arxitekturası:** məsuliyyətlərin ayrılması, konfiqurasiya, routing.
8. **Təhlükəsizlik:** password hashing, prepared statements, CSRF, output escaping.
9. **Keyfiyyət:** debugging, logging, testing, Git, code review.
10. **Layihələr:** CLI aləti, əlaqə forması, tələbə idarəetmə tətbiqi.

Tapşırıqları ötürməyin. Hər böyük bölmədən sonra işlək kiçik proqram yaradın.
