# PHP Learning Roadmap

1. **Language fundamentals:** syntax, variables, types, operators, conditions, loops.
2. **Reusable code:** arrays, functions, namespaces, Composer basics.
3. **Web fundamentals:** HTTP, request methods, forms, validation, escaping.
4. **State and files:** sessions, cookies, filesystem, uploads.
5. **Object-oriented PHP:** classes, interfaces, traits, exceptions.
6. **Databases:** relational design, MySQL, PDO, transactions, CRUD.
7. **Application architecture:** separation of concerns, configuration, routing basics.
8. **Security:** password hashing, prepared statements, CSRF protection, output escaping.
9. **Quality:** debugging, logging, testing, Git, code review.
10. **Projects:** CLI utility, contact form, student management app.

Do not skip exercises. Build small working programs after each major section.
